## 📌Project Name:
### Social Event Project-Server

## 📝Description:
This is the backend server for the social Event Project, a community-focused web application that allows users to create, explore and join social  events.

## 🚀Using Tchnologies:
 - Node,js
 - Express.js
 - MongoDB Drive
 - Cors
 - Dotenv

## 💡Important Features:
 1. Create and manage social events
 2. Get Upcomig events
 3. Get event detais
 4. Join Events
 5. Update and delete events
 6. MongoDB Database storage
 7. Authentication-ready API with protected routes
